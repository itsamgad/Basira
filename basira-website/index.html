Features

Why Basira?

Six load-bearing capabilities that turn messy spreadsheets into ML-ready datasets — without you writing a single line of pandas.

🌍

Bilingual Intelligence

Native Arabic + English handling — diacritics, hamza unification, tatweel removal, and 27 missing-token variants standardized to NaN.

🤖

Auto-Detect Everything

Column types, target column, task (classification / regression / clustering), and imputation strategy — all decided automatically.

🕷️

Built-in Web Scraper

No data? Click a single item, SHIFT-click each field — Basira's Chromium overlay extracts and pipes the result straight to the preprocessor.

📊

Full Audit Transparency

Every transformation is logged with row, column, action, before, and after — so you can defend every decision in your thesis or paper.

🎯

ML-Ready Output

Four files generated together: cleaned CSV, model-ready CSV (encoded + flagged), HTML audit report, and a JSON config for downstream engines.

🔓

Open Source

MIT-licensed, runs entirely on your laptop, no telemetry, no cloud uploads. Inspect or modify any threshold listed in the audit report.

How it works

Three steps from data to model-ready

The same pipeline runs whether you upload a file or scrape one from the web. No configuration screens to navigate — Basira makes the decisions and shows its work.

1
📥

Upload your data — or scrape it

Drop a CSV, XLS, or XLSX onto the dropzone. Or click "no data? no problem" to launch the built-in scraper and pull data from any website.

2
⚙️

Basira preprocesses automatically

Type detection, missing-token standardization, datetime expansion, imputation strategy selection, outlier flagging, and categorical encoding — all in seconds.

3
📦

Download your ML-ready files

Four artifacts: cleaned dataset, fully-encoded model input, an HTML audit report, and a JSON config that downstream Basira ML engines can consume directly.

Get Basira running locally

Same Python backend on both platforms. Pick your OS, follow the three-step install, you're done.

🍎

Download for macOS

⬇️ Download .zip
  1. 1Unzip the file.
  2. 2Drag Basira.app to /Applications/.
  3. 3First launch: right-click Basira.app → Open (Gatekeeper bypass).
  4. 4Use Launchpad or Spotlight from then on.

Requirements: macOS 11 (Big Sur) or newer · Python 3.10+ installed.

🪟

Download for Windows

⬇️ Download .zip
  1. 1Unzip the file.
  2. 2Double-click setup.bat (one-time, ~5 min).
  3. 3Double-click Basira.bat to launch.

Requirements: Windows 10 or newer · Python 3.10+ with "Add to PATH" enabled.
